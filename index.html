Projects

项目

01

EEG情绪识别

基于多通道脑电信号进行情绪状态识别，覆盖预处理、频域特征、深度学习分类和跨被试泛化评估。

  • Feature: PSD / DE / Connectivity
  • Model: CNN / Transformer
  • Status: 实验迭代中
02

SSVEP无人机

通过稳态视觉诱发电位识别用户意图，将频率编码目标转化为无人机方向、悬停和任务控制指令。

  • Signal: SSVEP frequency coding
  • Control: Real-time command loop
  • Status: 原型验证
03

脑控轮椅

面向辅助移动场景，融合脑电意图识别、环境感知与安全约束，实现更稳定的人机共享控制。

  • Task: Navigation assistance
  • Safety: Obstacle-aware control
  • Status: 系统集成
04

VLA机器人

探索视觉-语言-动作模型在机器人任务规划与执行中的应用，连接自然语言指令、视觉理解与动作策略。

  • Model: Vision-Language-Action
  • Scene: Manipulation / navigation
  • Status: 研究构建
